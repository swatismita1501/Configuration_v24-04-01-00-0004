#KEY INJECTION FORMAT
#KEY_LOCATION,USAGE,KEY_VALUE,BLOCK_FORMAT,KCV,KSN
#================================================
# All keys are injected in the clear except for Session keys 
#	multiple MK can be defined, corresponding session keys need to be following the MK definition before another MK is defined
# KEY_VALUE is encrypted key value (will take any value, if not doing Key Verification Calculation
# KEY_VALUE for DUKPT is the initial key (IK), this is in the clear
# BLOCK_FORMAT supported format are CLEAR TDES_ECB TDES_CBC AES192 TR31 
# KCV when set to 0, any data in KEY VALUE will be injected and used as valid key. 
# KSN for DUKPT only, 0 for all other key types
